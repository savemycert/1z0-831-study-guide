### Domain 1: Handling Date, Time, Text, Numeric and Boolean Values

**Weight: 11%.** Primitives and wrappers, expressions and casting, String/StringBuilder and text blocks, and the Date-Time API. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 1: Handling Date, Time, Text, Numeric and Boolean Values](notes/domain-1-handling-date-time-text-numeric-and-boolean-values.md)

- [ ] **Primitives, wrapper classes, operators and casting**
  <br>1: "Use primitives and wrapper classes. Evaluate arithmetic and boolean expressions, using the Math API and by applying precedence rules, type conversions, and casting."
  - 📖 Lesson: [Java Primitives, Wrapper Classes, Operators and Casting (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/ocp-java-primitives-wrappers-operators-casting/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: A whole-number literal is an int and a decimal literal is a double unless it ends in L or f; a leading 0 means octal.
  - Must know: byte, short and char operands are promoted to int before arithmetic, so the result needs a cast to go back to the narrow type.
- [ ] **Strings, StringBuilder and text blocks**
  <br>2: "Manipulate text, including text blocks, using String and StringBuilder classes."
  - 📖 Lesson: [Java Strings, StringBuilder and Text Blocks (OCP Java SE 25)](https://www.savemycert.com/revision/oracle-java-se-developer/java-string-stringbuilder-text-blocks/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: String is immutable: methods return a new String, and an unassigned result is lost; StringBuilder methods mutate the builder and return this.
  - Must know: == on Strings tests identity. Literals, compile-time constant expressions (including final constant variables), text blocks and intern() results share the pooled object; runtime concatenation and new String() do not.
- [ ] **Date-Time API: dates, times, durations, periods and time zones**
  <br>3: "Manipulate date, time, duration, period, instant and time-zone objects including daylight saving time using Date-Time API."
  - 📖 Lesson: [Java Date-Time API: Dates, Durations, Periods and Time Zones (OCP Java SE 25)](https://www.savemycert.com/revision/oracle-java-se-developer/java-date-time-api-period-duration-time-zones/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Every java.time object is immutable: plus, minus and with return a new object, and an unassigned result is lost.
  - Must know: of() factories validate at run time: months are 1-based, hours 0–23, and 29 February needs a leap year — otherwise DateTimeException.

**Weight: 8%.** if/else, switch statements and expressions, loops, break and continue. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 2: Implementing Program Flow Control Using Decision and Looping Constructs](notes/domain-2-implementing-program-flow-control-using-decision-and-looping-constructs.md)

- [ ] **if/else, switch statements and expressions, and loops**
  <br>1: "Create program flow control constructs including if/else, switch statements and expressions, loops, and break and continue statements."
  - 📖 Lesson: [Java Flow Control: if/else, switch and Loops (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-flow-control-if-switch-loops-break-continue/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Without braces, an else binds to the nearest unmatched if, whatever the indentation, and only one statement belongs to each branch.
  - Must know: Conditions must be boolean or Boolean; assigning an int in a condition does not compile, while assigning a boolean compiles and tests the assigned value.

### Domain 3: Applying Object-Oriented Principles in Java Programs

**Weight: 18%.** Objects and their life cycle, classes and records, overloading, scope and immutability, inheritance with abstract and sealed types, interfaces and enums. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 3: Applying Object-Oriented Principles in Java Programs](notes/domain-3-applying-object-oriented-principles-in-java-programs.md)

- [ ] **Objects, nested classes and the object life cycle**
  <br>1: "Declare and instantiate Java objects including nested class objects, and explain the object life-cycle including creation, reassigning references, and garbage collection."
  - 📖 Lesson: [Java Objects, Nested Classes and Garbage Collection (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-objects-nested-classes-garbage-collection/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: A variable holds a reference, not an object; only new (or an array creation) creates objects, and unassigned reference fields are null.
  - Must know: Mutating through an alias changes the shared object; reassigning a variable changes only that variable.
- [ ] **Classes, records, constructors and initializers**
  <br>2: "Create classes and records, and define and use instance and static fields and methods, constructors, including flexible constructor bodies, and instance and static initializers."
  - 📖 Lesson: [Java Classes, Records, Constructors and Initializers (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-classes-records-constructors-initializers/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: A static field is one variable per class shared by every instance; an instance field is a fresh copy in each object, and static code cannot use one without naming an object.
  - Must know: The default no-argument constructor exists only when a class declares no constructors; a member with a return type, even void, is a method, not a constructor.
- [ ] **Overloaded and var-arg methods**
  <br>3: "Implement overloaded methods, including var-arg methods."
  - 📖 Lesson: [Java Method Overloading and Varargs Rules (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-method-overloading-varargs/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: An overload must differ in its parameter types or their order; return type, parameter names, static, access modifiers and throws do not make a new signature.
  - Must know: Overload resolution runs three phases in order — widening, then boxing/unboxing, then varargs — and stops at the first phase with a candidate.
- [ ] **Scope, encapsulation, immutability, var and unnamed variables**
  <br>4: "Understand variable scopes, apply encapsulation, and create immutable objects. Use local variable type inference and unnamed variables."
  - 📖 Lesson: [Java Variable Scope, Encapsulation, Immutability, var and _ (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-variable-scope-encapsulation-immutability-var/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: A local is in scope from its declaration to the end of its block; it cannot be redeclared in an inner block while still in scope, but a field can be shadowed.
  - Must know: A colon-style switch block is one scope, so a local declared under one case is visible (but not initialized) under later cases; arrow cases each have their own block.
- [ ] **Inheritance, abstract and sealed types, overriding and polymorphism**
  <br>5: "Implement inheritance, including abstract and sealed types as well as record classes. Override methods, including that of the Object class. Implement polymorphism and differentiate between object type and reference type."
  - 📖 Lesson: [Java Inheritance, Polymorphism, Overriding and Sealed Classes (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-inheritance-sealed-classes-polymorphism-overriding/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: The reference type decides what compiles — callable members, overload choice and checked exceptions; the object type decides which overriding instance method body runs.
  - Must know: An override needs the same signature, the same or wider access, the same or a covariant return type, and no new or broader checked exceptions; different parameter types make an overload.
- [ ] **Interfaces, functional interfaces and interface methods**
  <br>6: "Create and use interfaces, identify functional interfaces, and utilize private, static, and default interface methods."
  - 📖 Lesson: [Java Interfaces: Functional, Default, Static and Private Methods (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-interfaces-functional-default-static-private-methods/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Interface abstract methods are implicitly public abstract, so the implementing method must be declared public; a blank modifier in a class means package access.
  - Must know: An abstract class can implement an interface partially; the first concrete subclass must supply every remaining abstract method.
- [ ] **Enums with fields, methods and constructors**
  <br>7: "Create and use enum types with fields, methods, and constructors."
  - 📖 Lesson: [Java Enums: Fields, Methods and Constructors (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-enum-fields-methods-constructors/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Constants come first, then a semicolon, then members; every constant's argument list must match a declared constructor.
  - Must know: Enums implicitly extend Enum: they can implement interfaces but never extend a class, and no class can extend them; local enums are legal.

📝 Revision notes: [Domain 4: Implementing Exception Handling in Java Applications](notes/domain-4-implementing-exception-handling-in-java-applications.md)

- [ ] **try/catch/finally, try-with-resources, multi-catch and custom exceptions**
  <br>1: "Handle exceptions using try/catch/finally, try-with-resources, and multi-catch blocks, including custom exceptions."
  - 📖 Lesson: [Java Exception Handling: try/catch/finally, try-with-resources and Custom Exceptions (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-exceptions-try-catch-finally-try-with-resources/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)

### Domain 5: Using Arrays and Collections to Store and Retrieve Data

**Weight: 8%.** Arrays, List, Set, Map, Deque and sequenced collections — adding, removing, updating, retrieving and sorting. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 5: Using Arrays and Collections to Store and Retrieve Data](notes/domain-5-using-arrays-and-collections-to-store-and-retrieve-data.md)

- [ ] **Arrays, List, Set, Map, Deque and sequenced collections**
  <br>1: "Create arrays, List, Set, Map, Deque, and sequenced collections, and add, remove, update, retrieve, and sort their elements."
  - 📖 Lesson: [Java Arrays and Collections: List, Set, Map, Deque and Sequenced Collections (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-arrays-collections-list-set-map-deque/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: New array elements default to 0, 0.0, false, '\u0000' or null; the last index is length - 1; int[] g[] is an int[][]; only the first dimension of new int[3][] is required, and its unassigned rows are null.
  - Must know: Arrays don't override equals or toString — use Arrays.equals, Arrays.toString and Arrays.compare/mismatch; clone() of a 2D array shares the rows.

### Domain 6: Processing Data Using Streams and Lambda Expressions

**Weight: 9%.** Object and primitive streams with lambdas, plus decomposition, concatenation, reduction, grouping, partitioning and gatherers. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 6: Processing Data Using Streams and Lambda Expressions](notes/domain-6-processing-data-using-streams-and-lambda-expressions.md)

- [ ] **Object and primitive streams with lambda expressions**
  <br>1: "Use Java object and primitive Streams, including lambda expressions implementing functional interfaces, to create, filter, transform, process, and sort data."
  - 📖 Lesson: [Java Streams, Lambdas and Primitive Streams (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-streams-lambda-expressions-primitive-streams/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Nothing runs without a terminal operation; elements then pass through all stages one at a time, and short-circuiting operations stop early.
  - Must know: A stream is single-use: a second operation on the same stream object throws IllegalStateException at that call, never a compile error.
- [ ] **Reduction, grouping, partitioning and gatherers on streams**
  <br>2: "Perform decomposition, concatenation, reduction, grouping and partitioning, and gather operations on sequential and parallel streams."
  - 📖 Lesson: [Java Stream Reduction, Grouping, Partitioning and Gatherers (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-stream-reduction-grouping-partitioning-gatherers/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: reduce(identity, op) returns T, reduce(op) returns Optional, and reduce(identity, accumulator, combiner) returns a different type U; only the three-argument form can change type, and Optional.stream() turns a result into a zero- or one-element stream.
  - Must know: A reduce accumulator that produces null as the final result throws NullPointerException; Optional.empty means only that the stream was empty.

### Domain 7: Packaging and Deploying Java Code

**Weight: 9%.** Modules, services and module imports; compiling and running source (compact source files, instance main), JARs, runtime images and migration to modules. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 7: Packaging and Deploying Java Code](notes/domain-7-packaging-and-deploying-java-code.md)

- [ ] **Modules, services and module import declarations**
  <br>1: "Define modules and expose module content, including that by reflection, declare module dependencies, define services, providers, and consumers, and use module import declarations."
  - 📖 Lesson: [Java Modules, Services and Module Imports (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-modules-services-module-imports/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Cross-module access needs three things: the module reads the other module, the package is exported to it, and the type and member are public.
  - Must know: exports names exactly one package; subpackages are unrelated, wildcards do not exist, and a duplicate export of the same package is a compile error.
- [ ] **Compiling and running code, JARs, runtime images and migration to modules**
  <br>2: "Compile and run Java source code, including compact source files, instance main methods, and multi-file source-code programs; create modular and non-modular jars and runtime images; and implement migration to modules using unnamed and automatic modules."
  - 📖 Lesson: [Compiling and Running Java: Compact Source Files, JARs, jlink and Module Migration (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-compile-run-jars-jlink-module-migration/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: A compact source file is an implicitly declared final class in the unnamed package: default constructor only, no package declaration, a required main method, and no code can refer to it by name.
  - Must know: Compact source files import all of java.base automatically; java.lang.IO is usable from every class without an import, but an ordinary class must still import java.util.List and friends.

### Domain 8: Implementing Multithreading for Concurrent Code Execution

**Weight: 11%.** Platform and virtual threads, executors and scoped values, thread safety with locks and the concurrent API, and concurrent collections and parallel streams. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 8: Implementing Multithreading for Concurrent Code Execution](notes/domain-8-implementing-multithreading-for-concurrent-code-execution.md)

- [ ] **Platform and virtual threads, executors and scoped values**
  <br>1: "Create both platform and virtual threads. Use Runnable and Callable objects, manage the thread lifecycle, use different Executor services and concurrent API to run tasks, and use scoped values to share immutable context."
  - 📖 Lesson: [Java Threads, Virtual Threads, Executors and Scoped Values (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-virtual-threads-executors-callable-scoped-values/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: start() runs the task on a new thread; calling run() runs it on the current thread. A Thread can be started only once: a second start() throws IllegalThreadStateException.
  - Must know: Virtual threads are always daemons, have a fixed priority of 5 and an empty default name, support ThreadLocal, and should be created per task, never pooled; setDaemon(false) throws IllegalArgumentException.
- [ ] **Thread-safe code with locks and the concurrent API**
  <br>2: "Develop thread-safe code, using locking mechanisms and concurrent API."
  - 📖 Lesson: [Java Thread Safety: synchronized, Locks, volatile and Atomic Variables (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-thread-safety-synchronized-locks-atomic-variables/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: count++ and x = x + 1 are read-modify-write: without a shared lock or an atomic class, concurrent updates are lost and the result can change from run to run.
  - Must know: A synchronized instance method locks this, a static synchronized method locks the Class object, a block locks the object its expression evaluates to — two calls exclude each other only on the same object.
- [ ] **Concurrent collections and parallel streams**
  <br>3: "Process Java collections concurrently and utilize parallel streams."
  - 📖 Lesson: [Java Concurrent Collections and Parallel Streams (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-concurrent-collections-parallel-streams/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Synchronized is not concurrent: Vector and Collections.synchronizedX make single calls safe, but their iterators still fail fast; java.util.concurrent iterators never throw ConcurrentModificationException.
  - Must know: Iterate or check-then-act on a synchronized wrapper inside synchronized (wrapper); the wrapper's own forEach is already locked, its stream is not.

### Domain 9: Performing Input and Output Operations Using the Java I/O API

**Weight: 11%.** Console and file I/O streams, serialization, and Path objects with the java.nio.file API. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 9: Performing Input and Output Operations Using the Java I/O API](notes/domain-9-performing-input-and-output-operations-using-the-java-i-o-api.md)

- [ ] **Console and file I/O streams**
  <br>1: "Read and write console and file data using I/O streams."
  - 📖 Lesson: [Java I/O Streams: Console and File Readers, Writers and Streams (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-io-streams-console-file-readers-writers/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Reader/Writer subclasses are character streams; InputStream/OutputStream subclasses are byte streams — PrintStream prints text but is a byte stream.
  - Must know: read() returns 0–255 (or a char) and -1 only at end of stream; read(buf) returns a count and leaves the rest of the array untouched.
- [ ] **Serialization and deserialization**
  <br>2: "Serialize and de-serialize Java objects."
  - 📖 Lesson: [Java Serialization and Deserialization: Serializable, transient and serialVersionUID (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-serialization-deserialization-serializable-transient/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Serializable is checked at run time: writing an object graph that reaches a non-serializable value throws NotSerializableException; null fields and static fields are never a problem.
  - Must know: readObject returns Object, declares IOException and ClassNotFoundException, and signals the end of the stream with EOFException, never null.
- [ ] **Path objects and the java.nio.file API**
  <br>3: "Construct, traverse, create, read, and write Path objects and their properties using the java.nio.file API."
  - 📖 Lesson: [Java NIO.2 Path and Files API: Build, Traverse, Read and Write (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-nio-file-path-files-api/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Creating or manipulating a Path never touches the disk; only Files methods and toRealPath do.
  - Must know: The root is not a name element: getNameCount, getName and subpath count only the names after it, and subpath is zero-based, end-exclusive and relative.

### Domain 10: Developing Applications with Localization Support

**Weight: 7%.** Locales and resource bundles; parsing and formatting messages, dates, times, numbers, currency and percentages. Oracle publishes no domain weights; weight approximates the objective share, with a floor for every section.

📝 Revision notes: [Domain 10: Developing Applications with Localization Support](notes/domain-10-developing-applications-with-localization-support.md)

- [ ] **Locales, resource bundles and formatting**
  <br>1: "Implement localization using locales and resource bundles. Parse and format messages, dates, times, and numbers, including currency and percentage values."
  - 📖 Lesson: [Java Localization: Locales, Resource Bundles and Formatting Numbers, Dates and Messages (1Z0-831)](https://www.savemycert.com/revision/oracle-java-se-developer/java-localization-resource-bundles-number-date-formatting/?utm_source=github&utm_medium=readme&utm_campaign=1z0-831-study-guide)
  - Must know: Locale.of never validates, forLanguageTag never throws for an ill-formed tag ("de_CH" gives Locale.ROOT), and Locale.Builder throws IllformedLocaleException; toString uses underscores, toLanguageTag hyphens.
  - Must know: Locale.setDefault(loc) resets the general default and both categories; a category call changes only FORMAT or DISPLAY. Formatters read FORMAT, getDisplay… names read DISPLAY, getBundle's fallback reads the general default.
